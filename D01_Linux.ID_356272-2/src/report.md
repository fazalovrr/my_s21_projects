## Part 8. Установка и базовая настройка сервиса SSHD
- Установиv службу SSHd.
`sudo apt-get update` 
`sudo apt-get install openssh-server`
<br>

- Добавим автостарт службы при загрузке системы
`sudo systemctl enable ssh`
<br>

-  Перенастроим службу SSHd на порт 2022:
   Отредактируем файл конфигурации: `sudo systemctl enable ssh`. Строку `#Port 22` и заменим на `Port 2022`.
<br>

-  Проверим наличие процесса sshd с помощью команды `ps aux | grep sshd`:

	   ![Настройка сервиса SSHD](img/p8_1.png)
   > ###### Значение команды:
   >- `ps` — отображает информацию о текущих процессах.
   >- `aux` — комбинация ключей:
   >  - `a` — показывает процессы всех пользователей.
   >  - `u` — выводит информацию о владельце процесса.
   >  - `x` — показывает процессы, не привязанные к терминалу.
   > - `grep sshd` — фильтрует вывод, показывая только строки, содержащие "sshd".

<br>

-  Перегружаем систему командой `reboot`.
<br>

-  Проверим порт службы SSH `netstat -tan` (должна быть строка `tcp 0 0 0.0.0.0:2022 0.0.0.0:* LISTEN`):
   ![Настройка сервиса SSHD](img/p8_2.png)
	> ###### Значение ключей `-tan`:
	> - `-t` — показывает только TCP соединения
	> - `-a` — показывает все соединения и прослушивающие порты
	> - `-n` — выводит адреса и порты в числовом формате, без попытки разрешения имен
	<br>

	> ###### Значение столбцов вывода:
	>   - `Proto` — протокол (TCP/UDP)
	>	- `Recv-Q` — количество байтов, ожидающих обработки
	>	- `Send-Q` — количество байтов, ожидающих отправки
	>	- `Local Address` — локальный адрес и порт
	>	- `Foreign Address` — удалённый адрес и порт
	>	- `State` — состояние соединения
		<br>
	> ###### Значение `0.0.0.0`:
	> - означает, что служба прослушивает на всех интерфейсах системы, что позволяет принимать соединения на этом порту с любого IP-адреса
	<br>
